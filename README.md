## 当前设计

纸色、森林绿和克制的浅绿强调；大字、留白与编辑式布局。首页为个人方向，随后是精选实践、交互方法演示、简洁经历和联系。求职只保留在联系区。

旧插画头像因视觉质量不合适已退出当前页面，原文件保留。主视觉由原生图像工具生成概念静物，不作为本人照片或手工Blender模型；专门压缩工具将网页版本处理为约309KB。

交互包括项目筛选、原生案例展开、案例深链接、明暗主题、手机导航、三层空间工作台、流程状态演示、复制邮箱及简历下载。无JavaScript时主要内容和导航仍可用；尊重减少动画设置。

## 文件与维护

- `index.html`：公开内容与语义结构。
- `assets/site.css`：视觉与响应式样式。
- `assets/site.js`：轻量交互。
- `assets/brand-still-life-v1.jpg`：当前品牌主视觉。
- `assets/favicon.svg`：本站图标。
- `assets/fonts/`：既有本地字体；字体使用SIL OFL 1.1许可。
- `404.html`：错误页返回入口。
- `CNAME`、`robots.txt`、`sitemap.xml`：域名与检索配置。
- `_dev/`：本地历史、草稿、原型及验证记录，已被Git忽略，不发布。
