    这个 JSON 能做什么？

    它包含任务、依赖、交付和验收条件，须审阅后交给你自己的本地执行器。本站不会安装软件、连接会员或自动开始任务。三阶段中的标记只用于推进流程，最终结果仍须检查。没有本地执行器时，可以直接使用下方 Markdown。

    任务包与“草稿 JSON”是两种不同文件；草稿用于恢复本页输入，任务包用于交接执行。每阶段提示词上限 2400 字符，超出时应拆分材料；长内容仍可导出 Markdown。
