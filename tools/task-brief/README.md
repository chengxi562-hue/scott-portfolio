# 协作任务单 · Task Brief

公开测试版 0.1。把 AI 协作需要的目标、材料、限制、交付与验收写清楚，生成给执行者和独立复核者的两份 Markdown 文本。

[在线使用](https://yichengxi.cn/tools/task-brief/) · [反馈问题](https://github.com/chengxi562-hue/scott-portfolio/issues)

填写任务信息，或载入一个明确标注的合成示例；生成后预览、复制或下载。继续编辑会清空过期输出并禁用旧复制按钮，需要重新生成。

- 无账号、API Key、模型调用或资料上传；复制到其他 AI 后，材料由该服务处理，请先检查是否可以分享。
- 仅暂存在当前标签页。关闭标签页或浏览器限制可能导致丢失，请下载留存。保存失败和损坏缓存会明确提示。
- 目标、交付格式和验收标准必填；未知项不自动补为事实。引用内容使用独立围栏，但文字提示不是安全沙箱，不能保证其他 AI 遵守要求。
- 研究、写作、代码三类任务。没有自动选模型、执行任务、联网检索、额度测算或云同步；当前为中文界面。任务文本并不能代替实际验收。
- 从根目录启动静态服务器，访问 `/tools/task-brief/`。核心测试：`node --test tools/task-brief/core.test.mjs`。不需要安装依赖或构建。
- 页面复用相邻 `evidence-brief/app.css` 与站点本地字体，因此单独拷贝此目录需要同时保留相对资源路径。

建议试用：用你可以分享的材料填写一项真实任务，把执行版交给正在使用的 AI，再用复核版检查实际结果。重点观察是否减少了澄清和漏项；尚无真实用户效果或节省比例的验证。

核心与界面初稿由现有 Kimi 会员分块提供，Codex 修订校验、存储提示、确认行为、共享样式和中文界面并完成验收。代码适用本目录 MIT 许可；用户填写的材料不因此改变权利归属。
