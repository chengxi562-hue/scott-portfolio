# 协作计划设计器 · Task Brief

2026-09-20 当前版，随站点提交 `a4d412b` 发布。[在线使用](https://yichengxi.cn/tools/task-brief/) · [反馈问题](https://github.com/chengxi562-hue/scott-portfolio/issues)

中文公开工具，把目标、材料、限制、交付和验收写清楚，生成执行/复核 Markdown、协作步骤预览与 `tongzhou.workflow` v1 JSON。纯浏览器规则生成，无账号、API Key、模型调用或资料上传。

## 使用与文件格式

1. 填写任务信息，或载入明确标注的合成示例。目标、交付格式和验收标准必填；未知项保持未知。
2. “生成任务单”提供执行版与复核版 Markdown，可预览、复制或下载。
3. “生成协作计划”提供单步执行；研究/写作还可选择“计划 → 初稿 → 复核”。代码任务仅支持单步。修改目标或材料时使用新的任务包标识。
4. 审阅任务包后交给自己的本地执行器。没有执行器时，使用 Markdown 逐条交接；本站不分发同舟的个人执行器、会员设置或凭证。

| 文件 | 用途与约束 |
|---|---|
| 草稿 JSON | `kind: task-brief`、`schemaVersion: 1`；恢复任务信息。最大 128 KiB，未填完也可下载；包含原始表单材料，请妥善保存。工作流标识和流程方式不随草稿保存，恢复后需重新确认。 |
| 工作流 JSON | `schema: tongzhou.workflow`、`version: 1`，包含 `tasks` 与 `notice`；1 或 3 步，`route:auto`，依赖按顺序排列，末步保留显式验收。供执行器整包验证后入队，不能作为草稿导入。 |
| Markdown | 给执行者或复核者阅读的任务文本，不用于恢复本页输入，也不会自动执行。 |

导入草稿只在当前浏览器内读取。已有内容会先确认替换；取消或坏文件保留当前内容，成功导入会清空旧产物。编辑任务信息、替换示例或清空表单都会使旧导出失效；修改工作流选项也须重新生成计划。

单步提示词最多 2400 个 Unicode 码位；三阶段复核提示最多 1950 个码位，为上游初稿预留空间。超限会拒绝生成，不静默删除材料；Markdown 仍受原表单长度限制。阶段标记仅用于推进流程，不证明内容正确。

## 能力边界

- 输入仅暂存在当前标签页。关闭标签页或浏览器限制可能造成丢失；请下载草稿并确认保存成功。没有云同步或跨设备保存；明暗偏好与网站共用 `site-theme`。
- 复制给其他 AI 后，内容由该服务处理；先确认材料可以分享，不填写密码、密钥或私人档案。
- 文本约束不是安全沙箱，不能保证其他 AI 遵守要求。引用材料不当作更高优先级指令，任务单也不代替实际验收。
- 不自动选模型、执行队列、联网检索或测算额度。尚无外部用户效果或节省比例的验证。

## 本地运行与验证

从仓库根目录启动静态服务器，访问 `/tools/task-brief/`，无需安装依赖或构建。需支持 ES modules、原生 dialog 与浏览器存储；不要直接双击 HTML。

```sh
python3 -m http.server 8080 --bind 127.0.0.1
node --test tools/task-brief/core.test.mjs tools/task-brief/draft.test.mjs tools/task-brief/workflow.test.mjs
```

`core.mjs` 生成任务单，`draft.mjs` 处理草稿格式，`workflow.mjs` 生成工作流，`app.mjs` 负责界面、存储和下载。页面复用相邻 `evidence-brief/app.css` 与站点字体，单独拷贝目录时需保留相对资源。
